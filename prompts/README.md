# Prompt Templates

Production system prompt templates referenced in the book. Each file is a ready-to-use prompt you can drop into your own agent systems.

| File | Use case |
|---|---|
| `orchestrator.txt` | Main orchestrator agent — task decomposition and delegation |
| `research-agent.txt` | Research agent — web search, source evaluation, synthesis |
| `content-agent.txt` | Content production agent — drafting, editing, formatting |
| `fact-checker.txt` | Fact-checking agent — claim verification against sources |
| `reflection.txt` | Reflection pass — critique and revision of agent outputs |
| `reviewer.txt` | Quality reviewer — structured evaluation against criteria |

## How to use

Each prompt is designed to be used as a system prompt. Replace placeholder values (indicated by `[BRACKETS]`) with your specific context before use.

These prompts implement the patterns described in Chapter 4 (Prompting and Reasoning) and Chapter 7 (Orchestration).
